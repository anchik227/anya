# mini-figma

Мини-клон Figma на React + TypeScript + Tailwind CSS + Vite.

## Команды

```bash
npm install      # установить зависимости
npm run dev      # dev-сервер (http://localhost:5173)
npm run build    # проверка типов + продакшен-сборка
npm run preview  # предпросмотр собранного проекта
```

## Архитектура

```
src/
  types/       — единый словарь типов (Shape, Tool, координаты)
  constants/   — константы (инструменты и их клавиши)
  utils/       — чистая математика (пересчёт экранных координат)
  hooks/       — логика без интерфейса (камера, фигуры, хоткеи)
  components/  — интерфейс (холст, фигура, панели)
```

## Что работает на этом шаге

- сетка на фоне холста
- панорамирование: зажать пробел + перетащить мышью
- зум колесом мыши от 10% до 400% (вокруг курсора)
- мир центрируется при старте
- рисование фигур: инструмент Rect (r) / Ellipse (o), тянем рамку мышью
- выделение фигуры кликом (инструмент Select, клавиша v) — рамка с маркерами
- перетаскивание выделенной фигуры мышью
- панель слоёв справа: клик по слою выделяет фигуру на канвасе
- панель свойств: заливка, обводка и её толщина для выделенных фигур
